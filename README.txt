نسخة مبسطة من موقع Free Fire Clash Squad
========================================

الملفات:
- index.html  صفحة الموقع
- style.css   التصميم والألوان
- script.js   التسجيل التجريبي والتفاعلات
- README.txt  تعليمات التشغيل

طريقة التشغيل:
1. ضع الملفات الأربعة في نفس المكان.
2. افتح index.html مباشرة في المتصفح.

ملاحظات:
- لا تحتاج هذه النسخة إلى Node.js أو قاعدة بيانات.
- التسجيلات التجريبية تحفظ في localStorage داخل المتصفح فقط.
- لوحة الإدارة والـ API غير موجودين في هذه النسخة الخفيفة.
